The footage was recorded from the public [demo pull request](https://github.com/JSv4/docxodus-action-demo/pull/1).
It demonstrates the public-repository `image-host: branch` option. The workflow
grants `contents: write`, discovers all changed DOCX files, and leaves Pages off.
The full Pages viewer remains optional. Cursor and focus highlights are recording
overlays; the document content and GitHub comment are the actual published output.
The download segment highlights the real artifact link in a signed-out browser;
GitHub requires sign-in to download the bundle.
Its fictional negotiation examples use the NVCA model charter; see the demo's
[document source attribution](https://github.com/JSv4/docxodus-action-demo/blob/main/documents/SOURCE.md).
The NVCA template and its derivatives are excluded from this repository's MIT
license. No third-party music or stock imagery is included.
